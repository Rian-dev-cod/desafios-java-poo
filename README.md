
==================================================
PROJETO JAVA — DESAFIOS DE APRENDIZADO (POO)
==================================================

SOBRE O PROJETO
--------------------------------------------------
Este projeto reúne uma sequência de desafios práticos
desenvolvidos em Java com o objetivo de consolidar
fundamentos da Programação Orientada a Objetos (POO).

O desenvolvimento foi feito de forma incremental,
com foco em entendimento real dos conceitos, código
organizado e boas práticas utilizadas no mercado.

--------------------------------------------------
FERRAMENTAS UTILIZADAS
--------------------------------------------------
- IDE (VS Code / IntelliJ)
- Programação Orientada a Objetos
- Collections (List, ArrayList)
- Enum
- Herança, Polimorfismo e Abstração
- Controle de acesso (private, protected)
- Boas práticas de organização de código

--------------------------------------------------
DESAFIOS DESENVOLVIDOS
--------------------------------------------------

NÍVEL 01 ao 04 — LÓGICA E FUNDAMENTOS
- Entrada e saída de dados
- Estruturas condicionais (if / switch)
- Estruturas de repetição (for / while)
- Métodos simples
- Organização básica de código

Ferramentas:
- Tipos primitivos
- Scanner
- Controle de fluxo

--------------------------------------------------

NÍVEL 05 ao 07 — MANIPULAÇÃO DE OBJETOS E ESTADO
- Criação de classes
- Uso de atributos e métodos
- Manipulação de String
- Criação de histórico com arrays
- Validação de índice e estado do objeto

Ferramentas:
- Classes e métodos
- Encapsulamento
- Arrays
- Laços de repetição

--------------------------------------------------

NÍVEL 08 — SEPARAÇÃO DE RESPONSABILIDADES
- Separação entre lógica e interface
- Menu responsável apenas por interação
- Classe de lógica sem Scanner e sem print
- Organização do código como em sistemas reais

Ferramentas:
- Boas práticas de design
- Responsabilidade única
- Organização em múltiplas classes

--------------------------------------------------

NÍVEL 09 — ENCAPSULAMENTO
- Atributos privados
- Controle de acesso com getters
- Proteção do estado interno da conta
- Métodos retornando sucesso ou falha

Ferramentas:
- Encapsulamento
- Controle de acesso
- Retorno booleano

--------------------------------------------------

NÍVEL 10 — HERANÇA
- Criação de classe base (Conta)
- Criação de classes filhas (ContaCorrente, ContaPoupanca)
- Reaproveitamento de código
- Regras de saque diferentes por tipo de conta

Ferramentas:
- Herança
- Override de métodos
- protected

--------------------------------------------------

NÍVEL 11 — POLIMORFISMO
- Uso de referência do tipo pai
- Execução de comportamentos diferentes
- Decisão em tempo de execução
- Eliminação de if, instanceof e cast

Ferramentas:
- Polimorfismo
- Arrays de objetos
- Override

--------------------------------------------------

NÍVEL 12 — ABSTRAÇÃO
- Uso de classe abstrata
- Definição de métodos abstratos
- Forçar implementação nas classes filhas
- Impedir instanciação da classe base

Ferramentas:
- abstract class
- Métodos abstratos
- Polimorfismo

--------------------------------------------------

NÍVEL 13 — INTERFACES
- Criação de interface para contrato
- Implementação por diferentes classes
- Separação entre definição e implementação
- Código desacoplado

Ferramentas:
- interface
- Implementação múltipla
- Design orientado a contratos

--------------------------------------------------

NÍVEL 14 — TRATAMENTO DE ERROS (EXCEÇÕES)
- Entendimento do fluxo de exceções
- Separação entre regra de negócio e tratamento
- Uso correto de try/catch no ponto de chamada
- Evitar tratamento espalhado no código

Ferramentas:
- Exceptions
- try / catch
- RuntimeException
- IllegalArgumentException

--------------------------------------------------

NÍVEL 15 — MODELAGEM MAIS REALISTA
- Composição (Conta possui Cliente)
- Criação de histórico de operações
- Uso de List para armazenar dados
- Classe Operacao para representar ações
- Enum com comportamento (TipoOperacao)

Ferramentas:
- List / ArrayList
- Enum com métodos
- Composição
- Organização de domínio

--------------------------------------------------
OBJETIVO PROFISSIONAL

prático e evolução contínua, buscando uma base sólida
